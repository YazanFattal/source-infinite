# SOURCE — A glimpse of the infinite

An imagined website of GOD: creation, stillness, and connection, expressed through original cosmic art, editorial typography, and gentle interaction.

## Experience

- Explore Light, Matter, and Life in an animated particle field; create your own spark.
- Enter a 60-second quiet moment, with optional breathing guidance, pause, restart, and Escape to close.
- Receive eight small invitations to kindness.
- On the Prayers page, release a private prayer or positive message into a personal constellation, with a reflection for Peace, Healing, Gratitude, or Hope.
- Revisit saved prayers or clear the sky. Prayers stay in local browser storage and are never transmitted or publicly shared. If storage is unavailable, the page keeps lights for the current visit and explains the limitation.
- Responsive design, keyboard navigation, native modal focus management, and respect for reduced-motion preferences.

The creative concept is universal and imaginative. The words are original reflections, not attributed divine statements.

## Use the source

The website is buildless. Its complete editable source is at the repository root: `index.html`, `styles.css`, `app.js`, `prayers.html`, `prayers.css`, `prayers.js`, and `assets/`. Publish with GitHub Pages by selecting **Settings → Pages → Deploy from a branch → main → / (root)**, or serve the repository root with any static web host. The `.nojekyll` file keeps GitHub Pages from applying Jekyll processing. No credentials, API calls, database, or installation are required. Kindness intentions on the home page remain in the current page session; released prayers are saved locally under `source.prayers.v1`.

Prayers accept up to 600 characters, with a maximum of 200 saved lights. The sky displays the most recent 36 lights; the saved-prayers list contains every saved prayer. Each selected intention has four original reflections; a local hash of the words chooses one and shapes the light's position. This is a visual transformation with curated reflections, without an AI service. User text is always inserted using `textContent`, never HTML. The page respects reduced-motion settings and provides a pause control. Clearing the sky requires a visitor confirmation.

Cormorant Garamond and DM Sans are licensed under the SIL Open Font License; notices accompany the font assets. The hero artwork was created with the built-in image generation tool and optimized as WebP for the site.

## Original artwork prompt

Use case: stylized-concept
Asset type: original square cinematic cosmic hero artwork for SOURCE, an imagined divine website, intended to sit beside warm ivory serif typography.
Primary request: an exquisitely detailed molten-gold luminous circular nebula / eclipse in an almost black warm charcoal cosmic void, evoking creation and divine awe.
Subject: one centered, beautifully irregular textured plasma ring, a delicate halo woven from innumerable fine flowing gold filament tendrils, with a tiny intense white-hot core at the exact center. The halo should feel natural and cosmic, neither perfect geometry nor a recognizable symbol. Wisps swirl fluidly around the ring and dissolve gently into darkness. Sparse faint stars.
Composition/framing: square artwork, approximately 1536 by 1536 pixels; centered subject; ring occupies about 60 percent of the frame; generous empty space all around. Outer edges must fade completely to uniformly near-black warm charcoal, close to #0b0c0b, for seamless integration onto a website.
Style/medium: premium cinematic astrophotographic conceptual artwork; restrained ethereal light; breathtaking fine detail, soft volumetric dust and intricate filaments; elegant and mysterious.
Color palette: warm almost-black charcoal, old gold, amber, pale champagne and tiny white-hot center. No cool blue or purple.
Constraints: no people, faces, deities, religious iconography, crosses, eyes, lettering, text, symbols, planets, spacecraft or watermark.
